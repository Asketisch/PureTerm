Implementation notes

· 外壳：标签栏 / 双侧栏 / 状态栏 / 浮层统一走 UiPalette 语义色
· 发光：仅 激活 tab · 焦点输入框 · 浮层面板 三处用 Shadow
· 终端：ANSI 16 色注入 colors[0..15]，具名色与 38;5;N 同时生效
· 性能：无新增 pipeline / render target，每帧仅多 16 次写入
· 开关：[appearance].preset = classic（默认） | cyberpunk
· 未包含：扫描线 / CRT / 文本辉光（shader 特效，需额外 pass）
